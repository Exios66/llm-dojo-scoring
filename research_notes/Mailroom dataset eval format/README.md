# Mailroom dataset evaluation research

These documents preserve research snapshots from October 17, 2026. Branch
heads, line-number citations, test results, and cross-repository status describe
those inspected checkouts, not the current integration state.

- `eval_format_best_practices.md`: evaluation dataset design research.
- `integration_surface.md`: historical consumer and producer integration map.
- `schema_alignment_audit.md`: historical schema and prompt alignment evidence.
- `subtype_extraction_scoring.md`: corporate-record schema design research.

The superseded `issue_inventory.md` has been removed rather than maintained as
a second live issue tracker; its original evidence remains in Git history.
Use GitHub issues and pull requests for current review and merge status, and
[`docs/TODOS.md`](../../docs/TODOS.md) for remaining connected-repository work.
Current dojo contracts are documented in
[`docs/CORPORATE_RECORD_SCHEMA.md`](../../docs/CORPORATE_RECORD_SCHEMA.md) and
[`docs/PROMPTS.md`](../../docs/PROMPTS.md), with prompt bytes and provenance
validated by the package tests.
